🎬 MovieApp
MovieApp is a modern iOS application designed for discovering and recommending movies based on user preferences. It combines AI-powered recommendations with a clean and intuitive interface.
🚀 Features
MVVM Architecture – Clean, testable, and maintainable code structure
Firebase Integration – Authentication & personalized user data
Core Data Storage – Favorites, watchlist, and custom statuses (Watched, Planned, Liked)
AI-Powered Recommendation System – OpenAI embeddings + cosine similarity for personalized movie suggestions
Dynamic UI with UIKit – UICollectionView & UITableView with Auto Layout
Modern Design – Glassmorphism toolbars, floating tab bars, responsive layouts
🛠️ Tech Stack
Language: Swift (UIKit)
Architecture: MVVM
Database: Core Data, Firebase
AI/ML: OpenAI Embeddings (text-embedding-ada-002), Cosine Similarity
API: TMDb (for movie data)
